Set up a church from the command line

One command creates the church, makes its first person the owner, and loads everything from a folder: songs from EasyWorship or plain text, and media. It is safe to run again, so you can add more later without doubling anything.

This is for whoever sets up the church: you, an IT volunteer, or an AI agent working for you. Day-to-day users do not need it. They use Import, then Church library in the app.

Before you start

  • The owner has signed in once. Open the app, go to Import, then Church library, and sign in with their email. That creates their account.
  • The source code. Clone the repository and run npm install. You need Node 22 or newer.
  • Two secrets, from whoever runs the church's Supabase project: its address (SUPABASE_URL) and its service-role key (SUPABASE_SERVICE_ROLE_KEY). The key can read and change everything, so give it to the command for that one run, keep it in a password manager, and never save it in a file or share it in chat.

1. Put the files in one folder

Folders inside folders are fine. The command sorts them by what they are:

  • An EasyWorship library: the folder with Songs.db and SongWords.db. Every song becomes a clean set of sections, with titles and capital letters tidied.
  • Text files (.txt): one song each. The file name is the title. Leave a blank line between sections, and put Verse 1 or Chorus on its own line to name one.
  • Media: pictures, video, audio, PDF, PowerPoint and Keynote are uploaded. A file over 500 MB is skipped and listed.

2. See what it will do

Add --dry-run and nothing is created or uploaded. It only counts.

npx tsx scripts/church-library/church.mts setup "Grace Community" --owner pastor@example.org --from ~/Church-Files --dry-run

It answers with how many songs and media files are ready, and names any song with no words.

3. Set it up

Run the same command without --dry-run, with the two secrets in the environment for this run only:

SUPABASE_URL=https://your-project.supabase.co \
SUPABASE_SERVICE_ROLE_KEY=... \
npx tsx scripts/church-library/church.mts setup "Grace Community" --owner pastor@example.org --from ~/Church-Files

If you use 1Password, op run can supply the key without it ever being shown or saved.

Add more later

npx tsx scripts/church-library/church.mts import "Grace Community" ~/New-Files

Songs are matched on where they came from, and media on its name and size, so files already there are not added twice.

Bring in the team

npx tsx scripts/church-library/church.mts invite "Grace Community" --role editor

It prints a code. Each person signs in to the app, opens Import, then Church library, and types it under Join. Roles: admin manages people, editor changes the library, viewer only reads, which suits a projection computer. The code works for 14 days.

If something stops

  • “No account for …”: the owner has not signed in to the app yet. Do step 1 of Before you start, then run it again.
  • A limit is reached: the free plan holds 500 songs and 1 GB of media. See plans.
  • Run it twice by mistake? Nothing doubles. It is built to be run again.

When it finishes, open the app, go to Import, then Church library, and press Sync songs. The songs appear in a category called Church library.
