Set up a church from the command line

One command creates your church, makes you its owner, and loads everything from a folder: songs from EasyWorship or plain text, and media. It is safe to run again, so you can add more later without doubling anything.

Anyone can do this for their own church. You sign in with your email, the same way as in the app, and there is no admin key to ask for. It suits a church admin, an IT volunteer, or an AI agent working for you. Prefer to click? Import, then Church library in the app does the same for a few songs at a time.

Before you start

  • The source code. Clone the repository and run npm install. You need Node 22 or newer.
  • Your email. You will be sent a sign-in code. It also creates your account if you do not have one.

1. Sign in

npx tsx scripts/church-library/church.mts login you@example.org

A code arrives by email. Type it in. You stay signed in on this computer, and the sign-in is kept in a private file only you can read. If you are working through an AI agent, it cannot type for you: run the command again with --code 123456 after the email arrives.

2. Put the files in one folder

Folders inside folders are fine. The command sorts them by what they are:

  • An EasyWorship library: the folder with Songs.db and SongWords.db. Every song becomes a clean set of sections, with titles and capital letters tidied.
  • Text files (.txt): one song each. The file name is the title. Leave a blank line between sections, and put Verse 1 or Chorus on its own line to name one.
  • Media: pictures, video, audio, PDF, PowerPoint and Keynote are uploaded. A file over 500 MB is skipped and listed. The video loops load this way too.

3. See what it will do

Add --dry-run and nothing is created or uploaded. It only counts.

npx tsx scripts/church-library/church.mts setup "Grace Community" --from ~/Church-Files --dry-run

It answers with how many songs and media files are ready, and names any song with no words.

4. Set it up

Run the same command without --dry-run:

npx tsx scripts/church-library/church.mts setup "Grace Community" --from ~/Church-Files

Add more later

npx tsx scripts/church-library/church.mts import "Grace Community" ~/New-Files

Songs are matched on where they came from, and media on its name and size, so files already there are not added twice. Anyone with the editor role or higher can add files.

Bring in the team

npx tsx scripts/church-library/church.mts invite "Grace Community" --role editor

It prints a code. Each person signs in to the app, opens Import, then Church library, and types it under Join. Roles: admin manages people, editor changes the library, viewer only reads, which suits a projection computer. The code works for 14 days. Only an owner or admin can make one.

If something stops

  • “Sign in first”: do step 1, or run it again if your sign-in has ended.
  • “You need to be an owner, admin or editor”: you are signed in, but not as someone who can change that church. Ask its owner for an invite.
  • A limit is reached: the free plan holds 500 songs and 1 GB of media. See plans.
  • Run it twice by mistake? Nothing doubles. It is built to be run again.

When it finishes, open the app, go to Import, then Church library, and press Sync songs. The songs appear in a category called Church library.
