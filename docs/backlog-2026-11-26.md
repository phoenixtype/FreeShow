- One item per commit. Write the named test first and watch it fail.
- Database changes are a **new** file in `supabase/migrations/`. Never edit an applied migration. Do not apply to the live project without the owner.
- No paid model call in any test. Mock `fetch`/`axios`.
- Do not push `main`: every push runs the Release workflow until R1 is done.
- New spoken requests go first into `src/frontend/ai/voice/churchRequests.test.ts`. Anything that puts scripture up goes through `src/frontend/ai/agent/presentPassage.ts`.
- House UI rules: no purple, no sparkle icons, no full-width buttons, buttons carry words, no hidden actions, sentence case, plain messages a volunteer can act on.
- Line numbers are from the audit commit. Re-read the lines before editing.
- "Checked" = confirmed by a second read of the code. "Reported" = found by one audit pass with file and line; confirm before changing.

## B. Wrong verse on screen (the headline feature)

All in `src/frontend/ai/scripture/` unless noted. Add a new `BibleSearchDetector.test.ts` with a small fixture Bible (John 3:1-36 with text, plus the canon). Auto-show thresholds: "high" shows above 75, "medium" above 50.

**B1. A sentence ending in "back" or "next" steps the verse.** Checked in part (`stt/transcript.ts:70-74`). S.
Every final segment is passed as a whole utterance; the worker emits the last word alone. "…Jesus is coming back." → previous verse.
Fix: accumulate segment text in `Transcript`; only on `utteranceEnd` pass the whole utterance to a new `AiManager.processUtterance(text)` that runs `parseCopilotCommand(text, true)`. Stop passing `textPart` at `transcript.ts:73`. Tests in `transcript.test.ts`.

**B2. Any number word, or "for", advances the verse.** Checked (`BibleSearchDetector.ts:119-130`, `mishearings.ts:75`). S.
On John 3:2, "he came by night for God was with him" → John 3:4 at 85. "wait a second" → next verse.
Fix: do not run the cue on the mishearing form; accept only a bare cardinal that starts the new words or follows sentence punctuation; when the Bible has text require 2 of the next 4 spoken words to be in the first 6 words of the cued verse; without text return 70.

**B3. Mishearing table rewrites ordinary words.** Checked. S.
`mishearings.ts:10,41,75`: "thank Mark for five years" → Mark 4:5 at 98; "let me ask three questions" → Exodus 3:1.
Fix: delete `for`; apply `ask, ex, exit, genius, josh, joan, romance, revolution(s)` and the short forms (`mat, dan, sam, tim, gal, col, mal, num, gen, rev, rom, phil, cor`) only when followed by `(chapter )?<digit>`.

**B4. Book name plus any number is a chapter; foreign number words leak into English.** Reported, run. M.
`BibleSearchDetector.ts:36-43`, `numbers.ts`, `numberDictionary.ts`. "John once said" → John 11:1 (Spanish). "Mark two things today" → Mark 2:1.
Fix: build number maps from English plus the spoken language only; give a chapter-only match 75 only with a chapter keyword, a lead-in ("turn to", "book of", "in", "read", "open") or the number at the end of the text, else 60; skip when the next word is `things|people|days|years|times|of|out|is|was|men|women|friends|letters`.

**B5. Ordinal before a book is always glued on.** Reported, run. S.
`BibleSearchDetector.ts:26-34`, `references.ts:9-10`. "First, John 3:16 tells us" → 1 John 3:16 at 98. "1st John 1:9" → John 1:9. "II Corinthians 5:17" → nothing.
Fix: retry without the prefix when the prefixed key is missing or out of range; normalise `1st|2nd|3rd|i|ii|iii` before numbered books; when punctuation followed the ordinal, return the unprefixed reading at 74.

**B6. Single-chapter books.** Reported, run. S. `references.ts:48-54`: "Jude one three" → Jude 1:1. Fix: when the chapter is 1 and a number follows, emit `book 1:<n>`. Also Philemon, Obadiah, 2 John, 3 John.

**B7. Psalms 101-150 as spoken.** Reported, run. S. `numbers.ts:46-98`: "Psalm one nineteen verse one oh five" → nothing; "Psalm one oh three" → Psalms 1:1. Fix: `(\d) (oh|o) (\d)` → three digits; `psalms? 1 (\d{2})` → `psalms 1$1` when ≤ 150.

**B8. Range end is not bounds-checked.** Checked (`BibleSearchDetector.ts:47-50`, also `:91-94`). S. "John 3 16 to 99" → "John 3:16-99". Fix: clamp to `chapterData.verseCount`.

**B9. Reading a verse inside the range on screen replaces the range.** Reported. S. `manager/AiManager.ts:263-266`. Fix: in `newMatch`, if the match is within `liveContent` (`isReferenceWithin`), call `heardAgain()` and return.

**B10. "from the beginning", "first chapter", "last chapter" jump mid-reading.** Reported. S. `voiceCommands.ts:141-146`. Fix: whole-utterance only (after B1); keep "go to the beginning" explicit. `voiceCommands.test.ts:33` changes with it.

**B11. "chapter three verse sixteen" in the current book is lost.** Reported, run. M. `references.ts:57-65`. Fix: exclude chapter/verse keywords from the book group; add a standalone-chapter match using the book on screen (80); after a chapter-only hit look ahead 60 characters for `verse N`.

**B12. "the twenty-third psalm" fails.** Reported, run. S. `references.ts:18-23,44`. Fix: `PSALM_PATTERN` accepts the plural; emit the Bible's own book name.

**B13. The name "Matthias" said in a sermon moves the screen.** Reported, probed. M.
`voice/matthiasAgent.ts:98-110,420-427`; `voice/matthias.ts:21,41`. "They prayed. Matthias. Next verse" navigates; "Matthias, Acts 1 verse 26, was numbered…" shows the passage whatever the "ask" setting.

**B14. A few lyric words in a sermon put a song up; slide following lags.** Reported. M. `songs/songDetection.ts:27,140,162-170`.
